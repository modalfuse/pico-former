# Reproducing the tables and figures

This file lists, for every table and figure of the revised manuscript, the command that produces it, the inputs it reads and the file it writes.

Paths are relative to the repository root: `code/` holds the scripts of the revised manuscript and `code/results/` the aggregate results they write; `firmware/` and `host/` are the firmware and host directories.

## 0. Local inputs

Checkpoints, window caches, and raw records are not distributed. The scripts locate them through two environment variables:

| Variable | Meaning |
| --- | --- |
| `PF_WORKSPACE` | Root of the local workspace. Expected layout: `rice-former/` (RICE-Former v1.0.6 checkout), `runs/20260830_s<seed>/` with `ckpt/ceqt.pt` and `cache/azt1d_s<seed>_str15.pkl` for seeds 20260828–20260830, and `validation/sample512.npz` (indices of the 512-window stratified sample) |
| `RICE_FORMER_SRC` | Optional; overrides `PF_WORKSPACE/rice-former/src` |

Window caches are built with RICE-Former v1.0.6 (AZT1D) and `code/build_external_cache.py` (OhioT1DM, DiaTrend). Weight headers are generated by `host/export_golden.py` (node firmware), `code/int8/prep_int8_data.py` and `code/int8/quantize_espdl.py` (ESP-DL builds), and `code/design_space/latency_fw/gen_bench_weights.py` (design-space latency builds). Board scripts read the Wi-Fi credentials and the API token from `firmware/wifi.yaml` (copy `firmware/wifi.yaml.example`).

## 2. Environments

| Use | Environment |
| --- | --- |
| Host evaluation, design-space training, board audit | Python 3.13, PyTorch 2.6.0, NumPy 2.2.3, pyserial; RICE-Former v1.0.6 `src/` on `PYTHONPATH` |
| Node firmware | PlatformIO Core 6.1.18, Arduino-ESP32 2.0.17 (`framework-arduinoespressif32` 3.20017, ESP-IDF 4.4.7), `xtensa-esp32s3-elf-gcc` 8.4.0 (esp-2021r2-patch5), `-Os` |
| Whole-model quantization | Python 3.10, PyTorch 2.3.0, ESP-PPQ 1.3.9 |
| ESP-DL and FP32-B firmware | ESP-IDF 5.5.3, ESP-DL 3.3.13 |

Board: ESP32-S3 QFN56 rev v0.2 (WiFiduino 32 S3; ESP32-S3-DevKitC-1 N16R8 for the second board), CPU 240 MHz, 16 MB quad flash QIO 80 MHz, 8 MB octal PSRAM 80 MHz, partition table `default_16MB.csv`. Serial audit at 460,800 baud.

Design-space training used the Apple GPU backend (MPS), which is not bit-reproducible: retraining one configuration with the same seed three times gave 1 h / 4 h MAE standard deviations of 0.010 / 0.018 mg/dL. All node results refer to the three checkpoint files identified above.

## 3. Data preparation

```bash
# AZT1D windows (seeds 20260828-20260830): RICE-Former v1.0.6, see its README
# OhioT1DM (12 test subjects) and DiaTrend (17 subjects with basal records)
python code/build_external_cache.py          # -> results/external_cache/{ohio,diatrend17}_str15.pkl
python host/export_golden.py                 # -> firmware/include/ceqt_weights.h, gold/ (needs RICE_CKPT, RICE_CACHE)
cd firmware && pio run -e s3_n16r8 -t upload # frozen node firmware
```
